# P1-2 — The README says a custom header overrides the same-named built-in "in …

## Finding / 问题

- EN: The README says a custom header overrides the same-named built-in "in both drivers". For To and Subject the native driver does not override: mail() still receives the real To and Subject while the custom header is appended, so the delivered message carries a duplicate, conflicting To: and Subject:. The SMTP driver overrides cleanly. (The reviewer notes the counter-argument that To/Subject are mail() arguments rather than native-driver "built-in headers", which would make this P2; the evidence is stated so the level can be re-graded without re-measuring.)
