# P3-8 — The README states absolutely that SmtpMailer "never writes a Bcc: …

## Finding / 问题

- EN: The README states absolutely that SmtpMailer "never writes a Bcc: header". A custom Bcc header is written verbatim (SmtpMailer has no built-in Bcc to shadow it) while the bcc addresses are still given to RCPT, so the claim is false in exactly the case a reader would rely on it.
- 中文: README 绝对化地声称 SmtpMailer「绝不写出 Bcc: 头」。但自定义 Bcc 头会被原样写出（SmtpMailer 没有可遮蔽它的内置 Bcc），同时 bcc 地址仍被 RCPT，于是该承诺恰好在读者会依赖它的那种情形下失实。
- Where / 位置: `README.md:129/:276 vs src/SmtpMailer.php:93-125`
- Verification / 验证: reproduced / 已实证
