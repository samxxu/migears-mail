# P2-2 — Attachment name and type are interpolated into quoted MIME parameters …

## Finding / 问题

- EN: Attachment name and type are interpolated into quoted MIME parameters without escaping " or \, so a quote in either value breaks the parameter and injects extra parameters into the part header. Both drivers share the flaw; the CRLF stripping already in place limits it to parameter injection rather than a new header line.
- 中文: 附件的 name 与 type 被直接插进带引号的 MIME 参数、未转义 " 或 \，值里的引号会破坏参数并向分部头注入额外参数。两个驱动同样有这个问题；已有的 CRLF 剥离把它限制在「参数注入」而非新增头行。
- Where / 位置: `src/NativeMailer.php:79,81 and src/SmtpMailer.php:165,167`
- Verification / 验证: reproduced / 已实证

## Thread

- 2026-10-01 · `reviewer — migears-full-review` · `open` — filed from the 6th round.
- 2026-10-01 · `owner — migears-mail` · `fixed` — reproduced, then fixed in both drivers. Before, name `a"b.txt` emitted `filename="a"b.txt"` (the inner quote closes the parameter early) and type `text/plain; x="evil` emitted `Content-Type: text/plain; x="evil; name="a"b.txt"`, injecting `x="evil` into the part header. Now `mimeParameter()` escapes `"` and `\` as a quoted-string (`name="a\"b.txt"`, `filename="a\"b.txt"`) and the media type has `"`/`\` stripped (`Content-Type: text/plain; x=evil; …`, `src/NativeMailer.php:70,81,83`, `src/SmtpMailer.php:156,167,169`), so neither value can break out of the parameter. Regression: `NativeMailerTest::testAttachmentNameAndTypeWithQuotesAreEscaped` and `SmtpMailerTest::testAttachmentNameAndTypeWithQuotesAreEscaped`. Mutation check (revert `src/` in a throwaway copy outside the repo): both FAIL.   中文：已复现并修复。修复前 name `a"b.txt` 输出 `filename="a"b.txt"`（内层引号提前闭合参数），type `text/plain; x="evil` 输出 `Content-Type: text/plain; x="evil; name="a"b.txt"`，向分部头注入 `x="evil`。现 `mimeParameter()` 按带引号字符串转义 `"` 与 `\`（`name="a\"b.txt"`、`filename="a\"b.txt"`），媒体类型则去掉 `"`/`\`（`Content-Type: text/plain; x=evil; …`），两个值都无法突破参数。回归用例两驱动各一条；变异检查（仓库外副本还原 `src/`）两条均 FAIL。门禁：phpunit `OK (99 tests, 225 assertions)`、phpstan `[OK] No errors`、composer validate 通过，退出码均 0。
